## Story

**As a** participante sem o conector ligado,
**I want** que a página da jam me diga o que fazer, inclusive se eu não tiver Node,
**so that** eu entre na jam sem procurar instrução em outro lugar.

## Acceptance Criteria

1. Enquanto o meu conector não está conectado, a página da jam mostra o
   passo de conexão com o aviso de que a jam precisa do Node.js (FR9).
2. Há um prompt pronto, com botão de copiar, para mandar ao Claude Code
   instalar o Node e o Git no Windows e confirmar as versões (o conector usa o
   Git para clonar e para respeitar o `.gitignore`).
3. O botão "Já instalei" mostra o comando de entrar
   (`npx coodevelopment entrar <id da jam>`), com botão de copiar.
4. Quando o meu conector conecta, o passo some sozinho; se ele cai, o passo
   volta (só para mim).
5. Sem conectar depois de 2 minutos no passo do comando, aparecem dicas:
   conferir o Node e rodar `npx coodevelopment diagnostico`.

## Escopo, dependências e riscos

**Entra:** componente "Passo de conexão" na página da jam, ligado à presença
da sala (Story 3.1: `conectados`); "Bloco de copiar" reutilizável (comando de
uma linha e prompt de várias linhas, botão "Copiar" com texto e estado
"Copiado" por 2 s, front-end spec); "Já instalei" lembrado por pessoa no
navegador (conveniência, `localStorage` com try/catch); dicas depois de 2 min;
passo só em jam aberta.

**Fica de fora:** aviso de aprovar o servidor MCP no Claude Code (Epic 4,
quando o conector instalar o plugin); "a pasta escolhida não é deste
repositório" na página (o conector ainda não conta isso à sala; hoje ele
explica no terminal); macOS e Linux no prompt.

**Depende de:** Story 3.1 (presença `conectados`, comando `entrar`, conector
no npm) e 2.5 (sala no ar). As duas em revisão em 29/10.

**Complexidade:** baixa (só front-end, sobre a presença que já existe).

**Riscos:**
1. Sem a sala (503, rede fora), a página não sabe se o conector está ligado:
   o passo aparece e fica, o que é o comportamento seguro (quem já está
   conectado vê um passo a mais, não um passo a menos).
2. A API de área de transferência pede contexto seguro e pode falhar: o bloco
   deixa o texto selecionável e avisa quando não copiou.
3. O prompt é texto para o Claude Code executar comandos no PC da pessoa:
   fica fixo no código, sem nada vindo do usuário ou da jam.

**Pronto quando:** os 5 ACs cobertos por testes de componente (presença
simulada, relógio falso para os 2 min, área de transferência simulada), axe
sem violações na página da jam em 1280 e 360 px, CI verde, e o passo some ao
ligar o conector em produção.
